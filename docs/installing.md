# Installing Bells and Whistles

Bells and Whistles 0.3.0 is a mod pack for Railroader 0.6.0, with the identifier `alex6511/bells-and-whistles`. The game's own mod system loads it.

!!! note "About this version"

    These pages describe the experimental 0.3.0 rework, which has not been tested in a running game yet. Follow the steps below if you have a 0.3.0 build. This documentation repository does not distribute mod binaries.

## What you need

- **Railroader 0.6.0.** This version of Bells and Whistles targets the game's native mod system.

You don't need any other mod, such as Unity Mod Manager or Library of Stuff.

## Install the mod

1. **Allow DLL mods.** In Railroader, turn on **Preferences → Allow Unsafe DLL Mods**, then restart the game. Bells and Whistles contains DLL files (compiled code). While this setting is off, the game refuses mods that contain DLLs.

2. **Copy the mod folder.**

    !!! warning "Remove an older copy first"

        You may have installed an earlier build of Bells and Whistles for Railroader 0.6.0 under another folder name. If so, delete that folder. Two installed packs with the same identifier collide, and the game skips one of them.

    Then copy the `bells-and-whistles` folder from the release zip into `Documents\Railroader\Mods\`. Replace any earlier copy.

3. **Enable the mod.** On the main menu, open **Mods** and enable **Bells and Whistles**.

## Next steps

If you only play, you're done.

To use the features in your own cars, read [For content authors](authors.md).
